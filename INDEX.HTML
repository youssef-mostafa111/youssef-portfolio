Featured Project

🛡 Smart Gas Leakage Detection & Safety System

Academic Team Project

Designed and developed a smart gas leakage detection system to reduce the risks of gas-related fires, explosions, and suffocation by combining real-time monitoring with automated emergency response.

Key Features

  • Real-time gas concentration monitoring using a gas sensor.
  • Displays gas levels on an LCD screen.
  • Activates an audible alarm when gas exceeds the safe threshold.
  • Automatically opens ventilation outlets.
  • Automatically shuts off the main gas supply valve.
  • Sends an SMS notification to the property owner.
  • If there is no response, the system automatically places a phone call to alert the owner.
